# 接口与状态契约

## 接口

版本、方法、路径、鉴权/对象归属、请求字段、响应信封、拆包所在层、错误码。
示例必须来自已确认契约或实际样本；不包含密钥。

## 边界

缺省/null/0/false/空数组；分页和排序；文件大小和路径；超时和重试；幂等键及重复操作。
权限字段由服务端可信身份导出，不让前端或模型自报决定。

## 状态

| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

## 兼容与证据

旧调用方、缓存、持久化、刷新、流式终态、迁移和回退；对应 AC 与层级证据。
