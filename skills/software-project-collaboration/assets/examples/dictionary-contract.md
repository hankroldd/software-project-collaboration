# 示例：下拉列表没有选项

## 已观察

后端返回结构为 {code, msg, data}；公共客户端已返回该body。页面API封装再取一次data后，页面仍按res.data读取，得到undefined。
编译通过，只说明语法和类型没阻断；不说明下拉真的出现。

## 最小完整修复

确认公共客户端的返回约定，在一个明确层负责拆信封；查看该API封装所有调用者，避免一处修好另一处改变返回形状。
不新建第二套网络客户端，不统一重写全部接口。

## 验证

1. 用真实契约形状构造mock，挂载/打开真实页面并点击指定下拉，断言预期选项可见。
2. 另在可用隔离实例走真实后端请求，核登录、信封、字典与页面显示。
3. 核空字典、接口失败与重新进入的反馈，按本次影响选取。

第1项是mock页面行为测试，不能命名为真实服务端到端验收。
如果第2项缺环境，报告第1项通过、第2项BLOCKED，不能把“后端200”代替选项可用。

## 文档

短spec记录信封拆包责任与选项验收即可；无需新PRD。证据写代码身份、契约夹具、执行命令、看到的结果与环境边界。
